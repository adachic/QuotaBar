01

Macに入れる

1

DMGを開く

上のボタンからダウンロードした QuotaBar-1.0.1-arm64.dmg をダブルクリックします。Intel Macはこの配布版の対象外です。

2

Applicationsへ移動

DMG内の QuotaBar.app を、隣の Applications フォルダへドラッグしてコピーします。

3

アプリを起動

「アプリケーション」からQuotaBarを開きます。画面上部に2つのゲージが出れば起動完了。Dockには表示されません。DMGは取り出して構いません。

開発元を確認できないという警告が出た場合：配布元と内容を確認し、起動すると判断した場合のみ「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選択します。詳しくはAppleの案内をご覧ください。

02

アカウントに接続する

</>Codex

  1. Codex CLIをインストールし、ChatGPTアカウントでログインしておきます。
  2. QuotaBarがCLIを自動検出し、利用枠を取得します。
  3. 見つからない場合は、QuotaBarの歯車からCodexの実行ファイルを選び、更新ボタンを押します。

APIキーだけの利用には対応していません。Codex CLIの公式案内 ↗

✳Claude Code

  1. Claude Codeをインストールし、/login でClaudeアカウントにログインしておきます。
  2. QuotaBarの歯車を開き、「Claude Codeに接続」をクリックします。
  3. キーチェーンのアクセス許可が求められたら、内容を確認して許可します。

APIキーだけの利用には対応していません。接続方式の制約はダウンロード前の注意点をご確認ください。

QuotaBarにパスワードやAPIキーを入力する必要はありません。利用枠がサービスから提供されるアカウントが必要です。

03

残量を見る・使いやすくする

メニューバーのどちらのゲージをクリックしても、両サービスの詳細が開きます。初期設定は「少ない方」、更新間隔は3分です。

表示・設定意味と操作
5時間 / 週間メニューバーに表示する枠を切り替えます。「少ない方」は取得できた2つの枠のうち、残りが少ない枠を表示します。
残りの％100 − 使用率。小数点以下は切り捨てます。詳細パネルでは20％以下でオレンジ、10％以下で赤になります。
「—」値が取得できない、またはアカウントにその枠が提供されていません。残量ゼロという意味ではありません。
前回の値 /「·」再取得に失敗した場合などの古い値です。接続状態を確認し、更新ボタンで再取得してください。
リセット確認待ちリセット予定時刻を過ぎたため、最新の残量が取得できるまで待機しています。
歯車の設定％の表示、更新間隔（1・3・5・15分）、Macへのログイン時の自動起動を変更できます。

好きな位置に並べる

⌘ Command を押しながらアイコンを左右にドラッグ。CodexとClaudeをそれぞれ移動できます。％をオフにすると表示の幅を抑えられます。

終了・アンインストール

詳細パネルの電源ボタンで終了できます。削除する場合は「ログイン時に起動」をオフにし、終了してからアプリをゴミ箱へ移動してください。

04

よくある質問

CodexやClaude Codeの画面を閉じても更新されますか？

QuotaBarが起動していてMacがスリープしていなければ、各アプリの画面を開いておく必要はありません。Codex CLIのインストール、有効なログイン情報、ネットワーク接続は必要です。期限切れの場合は元のアプリでログインし直してください。

画面を読み取っているのですか？

画面のスクレイピングは行いません。CodexはローカルCLIのApp Server経由で、Claude Codeは利用状況エンドポイントから取得します。接続方法の詳細も公開しています。

認証情報や利用状況はどこに送られますか？

開発者のサーバーには送信しません。Codexはインストール済みCLIに通信を任せます。Claudeのトークンはメモリで扱い、Anthropicの固定HTTPS宛先にのみ送信し、QuotaBarのログ・設定・キャッシュには保存しません。キーチェーン項目が存在しない場合のみ、Claude Code自身の認証ファイルを読みます。Codex CLIが自身の状態やログを更新することはあります。

接続エラーや更新されない表示を直すには？

まずネットワーク接続と、Codex／Claude Code側でログインできることを確認してください。その後、QuotaBarで再接続・更新します。アクセス制限（429）の場合は指定された待ち時間が終わってから再試行します。Claude側の仕様変更によって取得できなくなる場合もあります。

アプリを更新するには？

QuotaBarを終了して、新しいDMG内のアプリで「アプリケーション」のQuotaBarを置き換えてください。自動更新機能はありません。リリース一覧で更新を確認できます。

不具合を報告するには？

GitHub Issuesへ、macOSのバージョンと再現手順をお知らせください。認証ファイル、アクセストークン、APIキーは添付しないでください。
